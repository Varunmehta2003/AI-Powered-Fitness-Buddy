AI Integration Flows
⚡ IBM Granite Flow — watsonxService.ts
1
IAM Token Exchange
POST iam.cloud.ibm.com/identity/token
apikey=WATSONX_API_KEY → Bearer (55 min cache)
2
Build Prompt
System instructions + user context
+ last 6 conversation turns
Plain-text instruct format (not Llama tokens)
3
Inference Call
POST {WATSONX_URL}/ml/v1/text/generation
?version=2025-05-29
model_id = WATSONX_MODEL_ID
max_new_tokens: 500, greedy decoding
4
Return Response
results[0].generated_text → trim
→ chatService → frontend JSON
🌍 Orchestrate Flow — orchestrateService.ts
1
IAM Token Exchange
POST iam.cloud.ibm.com/identity/token
apikey=ORCHESTRATE_API_KEY → Bearer (separate cache)
2
Enrich Message
"Create workout [User Context: Goal: weight
management, Level: beginner, Time: 30 min…]"
3
Start Run
POST /v1/orchestrate/runs
{ agent_id, message: { role:"user", content } }
→ run_id, thread_id
4
Poll Run Status
GET /v1/orchestrate/runs/{run_id}
Every 2 s · terminal: completed|failed|cancelled
Timeout: 90 s
5
Read Reply
GET /v1/orchestrate/threads/{thread_id}/messages
→ last role=assistant message → content[].text
6
Return + Fallback
text + specialist label → frontend
If unavailable → automatic Granite fallback

Adaptive Workout Logic
too_easy
Streak counts. Next prompt: increase difficulty slightly. No aggressive changes on single session.
perfect
Streak extended. Completion rate up. Maintain or gradually progress next session.
too_hard
No streak penalty. Next prompt: reduce volume or use easier variations. No shame messaging.
not_completed
Counted in history. No streak break. Next prompt: shorter, more achievable session.
